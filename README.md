# Real-Time College Event Registration System

A real-time college event registration application using HTML, CSS, JavaScript and Firebase Realtime Database.

## Features
- Student event registration
- Live registration list
- Real-time updates without page refresh
- Duplicate register-number prevention
- Delete registration
- Live registration count

## Technologies
- HTML
- CSS
- JavaScript
- Firebase Realtime Database
- GitHub

## Setup
1. Create a Firebase project.
2. Enable Realtime Database.
3. Create a Web App in Firebase.
4. Copy the Firebase configuration into `script.js` and `admin.js`.
5. Run `index.html` using VS Code Live Server.
